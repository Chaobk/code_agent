## 会话行为

| 情况 | 行为 |
|---|---|
| 空白输入 | 跳过，不请求模型 |
| `/exit` 或 EOF | 结束会话，返回 0 |
| 输入时 Ctrl+C | 丢弃当前输入，重新提示 |
| 运行时 Ctrl+C | 取消当前 Task，等待进程和历史收尾 |
| 收尾时再次 Ctrl+C | 不重复取消同一个 Task |
| 正常、已知模型失败、步数耗尽 | 根据 RunResult 显示必要提示，继续输入 |
| 外部取消会话 | 收尾后继续传播取消 |
| 清理、内部或显示异常 | 诊断并结束会话，返回 1 |

会话复用同一个 Agent、History 和执行环境；每条输入独立计算 max_steps。取消不撤销磁盘修改，不自动重跑 unknown 命令。

## 实现边界

- UI 负责输入和信号，核心负责工具配对，Bash 负责进程和输出任务。
- `Agent.run` 返回 `RunResult`，进度事件不再携带运行终态。
- 核心只有一个历史结算出口；取消与致命失败都补齐当前 unknown 和剩余 not_started。
- REPL 不再监听结束事件，不维护 `finished_reason` 和 `run_started`。
- 退出时恢复原信号处理器，当前运行真正结束前不读取下一条输入。
